# Stanford Code in Place: First Principles Edition

> "Simplicity is the ultimate sophistication."

This repository is a complete deconstruction and re-engineering of the Stanford Code in Place curriculum. Instead of merely writing scripts to pass the assignments, every challenge here is treated as an exercise in **First Principles thinking, relentless reduction, and defensive programming.**

## The 3-Tier Architecture

To demonstrate the evolution of writing good software, every challenge in this repository is solved across three distinct levels:

*   **Level 1: Beginner (The "Make it Work" Level):** Linear, procedural execution. The absolute raw logic required to reach the finish line.
*   **Level 2: Intermediate (The "Storyteller" Level):** Focuses on modularity and decomposition. Code is broken down into custom, clearly named functions so the core logic reads like a story.
*   **Level 3: Advanced (The "Defensive & Documented" Level):** Production-ready code. Utilizes strict pre-conditions (`if` statements) and a standardized architectural blueprint to ensure the program never crashes, even in broken environments.
